well-known URI Registry

This specification adds the following value to the "Well-Known URIs" registry established by RFC 5785 [[RFC5785]].

  • URI suffix: lws-configuration
  • Change controller: W3C
  • Specification document: of this specification
  • Related information: (none)

OAuth Authorization Server Metadata Registry

This specification adds the following value to the "OAuth Authorization Server Metadata" registry established by [[RFC8414]].

  • Metadata Name: subject_token_types_supported
  • Metadata Description: JSON array containing a list of the OAuth 2.0 "subject_token_type" values that this authorization server supports
  • Change Controller: W3C
  • Specification Document(s): of this specification
  • Metadata Name: subject_identifier_types_supported
  • Metadata Description: JSON array containing a list of subject identifier types that this authorization server supports
  • Change Controller: W3C
  • Specification Document(s): of this specification
